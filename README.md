# Phantom Terminal Pro

Neon rainbow terminal banner and Zsh prompt for Termux.

## Install
```bash
pkg update -y
pkg install git -y
git clone https://github.com/rootphantom59/phantom-terminal-pro.git
cd phantom-terminal-pro
bash install.sh
```

The installer asks for Banner name, Username, and Host name in that order.
Restart Termux or run `zsh`, then use `pxhelp`.

Note: this package has not been device-tested in this environment. The banner uses a built-in 5x7 block font and terminal ANSI colors.
