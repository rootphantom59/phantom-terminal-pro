# ⚡ PHANTOM - Professional Termux Banner & Shell Setup ⚡

A stylish, customizable Termux theme featuring ANSI Shadow figlet banners, rainbow gradients, Zsh autosuggestions, syntax highlighting, and a Kali Linux prompt.

## 🚀 Installation

Run these commands inside your Termux:

```bash
pkg update && pkg install git -y
git clone [https://github.com/](https://github.com/)<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
cd <YOUR_REPO_NAME>
chmod +x install.sh banner.sh
./install.sh
